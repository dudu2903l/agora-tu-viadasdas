# Site de Recarga Gamer

Este projeto é uma landing page de recarga com redirecionamento para o site de destino configurado em `URL_DESTINO`.

## Como publicar no GitHub

1. Crie um repositório vazio no GitHub.
2. No terminal, execute:

```bash
git add .
git commit -m "Primeiro commit"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPO.git
git push -u origin main
```

## Destino

O redirecionamento atual aponta para:

https://jogo-recarga.vercel.app/
